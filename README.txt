INDUSTRIFLOW - Smart Production Scheduler Prototype

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No server, database, or installation is required for this prototype.

FEATURES
- Manual production order entry
- CSV upload
- Machine configuration
- Priority-aware scheduling
- Deadline-aware ordering
- Automatic machine selection
- Simple Gantt-style production schedule
- Makespan, waiting-time, utilization, and delayed-order metrics
- Responsive industrial dark-theme interface

CSV FORMAT
Order_ID,Product,Quantity,Priority,Processing_Time,Deadline,Required_Machine

Priority must be High, Medium, or Low.
Required_Machine may be blank for automatic assignment.

NOTE
This is a functional academic prototype. The displayed performance metrics are calculated
from the currently entered sample data and should not be treated as real-world factory claims.
